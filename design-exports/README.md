# 📥 design-exports — ที่เก็บงานจาก Claude Design

เอาไฟล์ HTML ที่ export จาก Claude Design มาวางที่นี่ (หรือก๊อปโค้ดมาแปะในแชท Cowork แล้วบอกให้ Claude เซฟให้)

## วิธีตั้งชื่อไฟล์ (ตามหน้า)
- `landing.html`
- `courses.html` · `course-detail.html`
- `checkout.html` · `pricing.html` · `about.html`
- `dashboard.html` · `learn.html` · `exams.html`
- `admin-*.html` (เช่น `admin-payments.html`)
- `gamification-*.html` · `notifications.html` · `onboarding.html` · `settings.html`
- `referral.html` · `contact.html` · `terms.html` · `privacy.html`
- `location.html` · `tcas-calculator.html`

> ถ้าหน้าไหนถูกเพิ่ม/เปลี่ยน/รวมใน Claude Design ก็ตั้งชื่อตามจริงได้เลย — ยึด Claude Design เป็นหลัก (ดู ROADMAP.md)

## ขั้นตอน
1. Claude Design → เปิดหน้า → copy โค้ด (หรือ download)
2. วางไฟล์ที่นี่ หรือแปะโค้ดในแชทให้ Claude เซฟ
3. บอก Claude ว่าเซฟครบแล้ว → Claude จะไล่พอร์ตเข้าโค้ด Next.js จริง
